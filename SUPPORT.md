# Support

Before opening an issue:

1. Check the latest Release and existing issues.
2. Reproduce the problem with default settings when possible.
3. Remove private information from screenshots and logs.

For bugs, include the Snipra version, Windows version, monitor count and DPI scaling, capture mode, exact steps, and relevant text from `%AppData%\Snipra\error.log`.

Feature requests should stay focused on screenshot capture, lightweight annotation, local OCR, and reliability.
