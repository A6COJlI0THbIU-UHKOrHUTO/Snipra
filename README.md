<h1 align="center">Snipra</h1>

<p align="center">A fast, local screenshot utility for Windows.</p>

<p align="center"><a href="../../releases/latest"><b>Download the latest release</b></a></p>

## Features

- Current monitor, active window, window picker, delayed capture, and all monitors.
- Crop, pencil, marker, lines, arrows, shapes, text, blur, cover, and spotlight.
- Independent **Copy** and **Save** actions.
- PNG/JPEG output to a folder chosen on first launch.
- Separate full-resolution documents for multi-monitor captures.
- Local text recognition through Windows OCR.
- Eight interface languages and light/dark themes.

## Install

1. Open the [latest Release](../../releases/latest).
2. Download `Snipra-Setup-win-x64.exe`.
3. Compare its SHA-256 value with `SHA256SUMS.txt`.
4. Run the installer — no administrator rights required. Autostart and shortcuts are optional checkboxes.
5. Choose the screenshot folder on first launch.

Windows may show a SmartScreen warning until the executable is code-signed.

## Privacy

Screenshots, settings, and OCR stay on the device. There are no accounts, analytics, telemetry, cloud uploads, or background network requests. Read [PRIVACY.md](PRIVACY.md) for details.

## Support

Use the issue templates for reproducible bugs and screenshot-focused feature requests. Remove personal data from screenshots and logs. Security reports should follow [SECURITY.md](SECURITY.md).

Быстрый локальный скриншотер для Windows.

### Возможности

- Текущий монитор, активное окно, выбор окна, задержка и все мониторы.
- Обрезка, карандаш, маркер, линии, стрелки, фигуры, текст, размытие, заливка и затемнение вокруг области.
- Отдельные действия **Копировать** и **Сохранить**.
- PNG/JPEG и выбор папки при первом запуске.
- Отдельные полноразмерные снимки для нескольких мониторов.
- Локальное распознавание текста через Windows OCR.
- Восемь языков интерфейса, светлая и тёмная темы.

### Установка

1. Открой [последний Release](../../releases/latest).
2. Скачай `Snipra-Setup-win-x64.exe`.
3. Сверь SHA-256 с `SHA256SUMS.txt`.
4. Запусти установщик — права администратора не нужны. Автозапуск и ярлыки — необязательные галочки.
5. При первом запуске выбери папку снимков.

До подписания файла Windows может показывать предупреждение SmartScreen.

### Приватность

Снимки, настройки и OCR остаются на устройстве. Нет аккаунтов, аналитики, телеметрии, облачной загрузки и фоновых сетевых запросов. Подробности — в [PRIVACY.md](PRIVACY.md).
